# Mol-JEPA Embedding Pipeline

Generates pretrained Mol-JEPA embeddings for compounds in the Harmonized Drug Dataset.

From the repository root:

```bash
pixi install --locked
pixi run --locked pipeline
```

The results CSV and QC HTML are written to `data/results/nextflow/`.

See [Running with Nextflow](docs/README.md#running-with-nextflow) for setup, commands, and outputs.
